## 13. Design/Theme Notes — LOCKED (Phase 2)

- Theme: Original comic-book/graphic-novel-inspired design. NOT using official Marvel/Sony assets, movie posters, game key art, or fan art of the copyrighted character — Saif uploaded several reference images (Marvel's Spider-Man game key art, Spider-Verse posters, fan art) for mood/tone only; none are reproduced in the actual build. Copyright constraint confirmed and agreed with Saif.
- Site structure: Single scrolling page with sticky nav
- Hosting: GitHub Pages (guidance needed — Saif is setting this up for the first time)
- Base tone: Light-to-medium dark (explicitly NOT full black) — landed on "twilight navy" (#151B2E), not ink black.

### Color palette (finalized)
- Twilight navy `#151B2E` — background base
- Navy deep `#0F1424` — secondary depth/gradient
- Signal red `#E4364A` — headings, primary accents, CTAs
- Web blue `#2F5DA8` — secondary accent, badge
- Paper white `#F4F1E8` — body text
- Impact amber `#F2B84B` — small highlights, eyebrow text (used sparingly)

### Typography
- Display/headings: **Bangers** (Google Font) — bold comic-book feel
- Body/UI: **Inter** — clean sans-serif for readability

### Signature design element
- Original circular monogram badge ("ST" initials, not any character's emblem) with a radial web-line texture, tilts in 3D on cursor movement (mousemove-driven CSS transform) — the page's signature interactive moment.
- Halftone dot texture overlay across hero background for comic-print atmosphere.
- Red/blue chromatic "double-exposure" text-shadow on the main heading.

### Assets
- Saif has a few of his own assets; will contribute wherever they fit (not yet placed into build).
- Reference images provided by Saif (for mood only, not reproduced): Marvel's Spider-Man PS4 key art, Into the Spider-Verse posters/fan art — used solely to calibrate energy/color, not copied.

### Phase 3 progress
- Initial static prototype (hero.html) validated the visual direction, then migrated to a real React app.

### Tech stack (LOCKED)
- Vite + React
